# login-page-capstone

A simple, responsive login page built with plain HTML, CSS, and JavaScript.

## Run locally

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser. No server, build step, or installation is required.

## Test

- Submit with either field empty to see the required-field validation.
- Use username `admin` and password `Admin@123` to see **Login Successful**.
- Try any other non-empty username or password to see **Invalid username or password**.
- Press Enter from either field to submit the form.
- Resize the browser window to check the responsive layout.

## Security notice

This is a demo-only authentication example, not production security. The demo credentials are included in client-side JavaScript and can be inspected by anyone. This page does not authenticate users securely, contact a backend, or store credentials in browser storage. Do not use this implementation to protect real accounts or data.
